Thank you for your interest in contributing to Project IMACE.

## How to Contribute

1. Fork the `main` branch (open‑source core).
2. Create a feature branch.
3. Write tests for your changes.
4. Ensure all tests pass (`make test-all`).
5. Submit a pull request.

## Code Style

- C++: clang-format (provided)
- Rust: rustfmt (provided)
- Python: black + isort (provided)
- Lisp: follow existing SBCL style

## Theoretical Alignment

All contributions must align with the research foundations documented in `/docs/theoretical-foundations.md` (to be added).
